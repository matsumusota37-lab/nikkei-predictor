# 日経平均 2営業日後 騰落予測モデル

## 何をするか
毎朝（東京市場の寄付き前）に以下を自動で行います。

1. **データ更新** … 日経平均と海外13市場の日足を Yahoo Finance（チャートAPI）から差分取得し `data/` に蓄積
2. **相関市場の選定** … 直近500営業日で「海外市場の当日リターン」と「日経の翌営業日リターン」の相関を測り、|相関| ≥ 0.15 の市場を採用（最低5市場）
3. **特徴量作成** … 日経のテクニカル指標＋採用市場のリターン
4. **再学習と検証** … ロジスティック回帰と勾配ブースティングを、ウォークフォワード検証（過去で学習→未来で検証×5回）で比較し、AUCの高い方を全期間で再学習
5. **予測** … 判定日（基準日の翌営業日）の朝に、翌営業日の引値が判定日当日の引値を上回る確率を出力（例：水曜朝に判定 → 木曜の引値が水曜の引値より上か下か）
6. **答え合わせ** … 過去の予測を実績と照合し `output/predictions.csv` に的中を記録

## 特徴量
| 区分 | 内容 |
|---|---|
| リターン | 1・2・5・10・20日 |
| トレンド | 移動平均乖離率（5・25・75日）、5日/25日線の位置関係、MACD・ヒストグラム |
| オシレーター | RSI(14)、ストキャスティクス%K(14)、ボリンジャー%B(20,2σ) |
| ボラティリティ | ATR(14)、20日ボラ、短期/長期ボラ比 |
| 出来高 | 20日平均比（データがある場合） |
| 追加テクニカル | 1〜3日前のリターン、曜日、月末接近、連騰/連敗日数、52週高値・安値からの距離、RSIの3日変化、ボラの5日変化、CME日経先物と日経平均の差 |
| 海外市場 | S&P500、ダウ、ナスダック、SOX、VIX、CME日経先物、ドル円、ユーロ円、米10年金利、原油、金、ハンセン、上海 から相関で選ばれたものの1日・5日リターン |

## 動かし方（パソコン）
```bash
pip install -r requirements.txt
python nikkei_predictor.py --demo   # 疑似データで動作確認
python nikkei_predictor.py          # 本番（初回は2012年以降を取得、約30秒）
```

## 毎朝自動で動かす（GitHub Actions・無料）
1. GitHub に非公開リポジトリを作り、このフォルダ一式をアップロード
2. Settings → Secrets and variables → Actions に3つ登録（メール不要なら省略可）
   - `GMAIL_USER` 送信元Gmailアドレス
   - `GMAIL_APP_PASSWORD` Googleアカウントで発行した「アプリパスワード」
   - `MAIL_TO` 受信アドレス
3. Actions タブで「Run workflow」を押して初回実行
4. 以後、平日 6:30（日本時間）に自動実行（GitHub側で10〜30分遅れることがあります）

## 値動き注意
予想対象日が「米雇用統計の翌営業日（第1金曜で近似）」「FOMC結果の翌朝」「メジャーSQ」に当たる日は、件名に【値動き注意】を付け、本文に理由を表示します。FOMC・日銀の日程は `data/events.csv`（2027年末まで）。年1回、FRBの公表日程に合わせて追記してください。

## 出力
- `output/latest_report.txt` … 最新予測レポート（メール本文と同じ）
- `output/predictions.csv` … 予測履歴と答え合わせ
- `output/market_correlation.csv` … 市場ごとの相関
- `output/walk_forward.csv` … 検証成績の明細
- `output/model.joblib` … 学習済みモデル

## 注意
- NYの引けは日本時間 5:00（夏時間）/ 6:00（冬時間）。それより前に実行すると前日の米国データが入りません。
- 株価の方向予測は正解率55%前後でも良い方です。「常に多数派を当てた場合」と比べて上回っているかで評価してください。
- 参考情報であり、投資判断を保証するものではありません。
